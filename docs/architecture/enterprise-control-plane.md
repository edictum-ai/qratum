# Enterprise Control Plane

A future self-hosted control plane may include qratum-api, qratum-worker,
qratum-web, Postgres metadata, object storage for blobs, queue-backed
processing, OIDC, RBAC, audit logs, policy distribution, and retention.

Raw transcripts do not upload by default.
